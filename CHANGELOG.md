# Changelog

All notable changes to Create: AlcoCraft+ are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0-beta]
### Added
- Initial release. Brings Create integration to AlcoCraft+ on Forge 1.20.1:
  - 12 beer fluids, one per beer type.
  - The keg accepts water and pushes out finished beer through Create pipes.
  - Beer mugs can be filled at a Create Spout (`create:filling` recipes).
  - Beer mugs act as fluid containers — usable as a Smart Fluid Pipe filter and drainable in an Item Drain.
